# FinanceMate

> Умный финансовый помощник для анализа транзакций, контроля расходов и улучшения финансовых привычек.

## 📌 О проекте

**FinanceMate** — это веб-сервис для управления личными финансами.
Платформа помогает пользователям:

* хранить историю транзакций;
* анализировать расходы;
* получать персональные рекомендации;
* отслеживать финансовые привычки;
* взаимодействовать со встроенным финансовым помощником.

Сервис ориентирован на упрощение повседневного финансового контроля и повышение финансовой грамотности пользователей.

## 🚀 Основные возможности

### 💳 Управление транзакциями

* Создание и просмотр транзакций
* Хранение истории операций
* Фильтрация и анализ расходов по категориям

### 📊 Аналитика

* Построение графиков и диаграмм

* Регистрация и вход через email
* Аутентификация пользователей

## 🏗 Архитектура проекта

Проект разделён на несколько основных компонентов:

* **Frontend** — пользовательский интерфейс
* **Backend** — REST API и бизнес-логика
* **Database** — хранение пользователей и транзакций
* **Analytics** — анализ данных и рекомендации

## 🤖 Финансовый помощник

Финансовый помощник анализирует поведение пользователя и:

* формирует ежемесячные отчёты;
* сравнивает траты с пользователями из аналогичной группы;
* выявляет аномальные расходы;
* предлагает рекомендации по улучшению финансовых привычек.

## 🐳 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/tuhlopuz1/FinanceMate.git
cd FinanceMate
```

### 2. Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 3. Frontend

```bash
cd frontend
npm install
npm start
```

### 4. Docker

```bash
docker-compose up --build
```
